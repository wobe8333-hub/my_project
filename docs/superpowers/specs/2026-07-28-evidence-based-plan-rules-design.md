# 근거 기반 운동/식단 규칙 반영 설계

## 배경
`lib/planGenerator.ts`는 사용자 프로필을 그대로 AI 프롬프트에 넣어 7일 운동/식단을 생성한다. 근거 기반 트레이닝 원칙(빈도, 볼륨, 세트/휴식, 단백질 섭취량 등)이 프롬프트에 명시돼 있지 않아 AI 출력 품질이 들쭉날쭉했다.

## 리서치 근거 (2026 ACSM Position Stand 등)
- 주요 근육군 최소 주 2회, 비연속일 훈련
- 근성장: 근육군당 주 4~20세트 (권장 10~20), 8~12회 반복, 70~85% 1RM
- 근력: 2~3세트, 80% 1RM
- 세트간 휴식: 초중급 1~2분, 고급 1~3분
- 점진과부하: 무게 2~10%↑ 또는 횟수/세트/휴식/이센트릭/가동범위 중 하나 조정. 초보 거의 매회, 중급 매주, 고급 매월 진행
- 홈트/맨몸도 초중급자에겐 헬스장과 동등한 효과 (점진과부하만 지키면 도구 무관), 5대 동작 패턴(밀기/당기기/스쿼트/힌지/코어) 중심 구성
- 단백질: 벌크 1.8~2.2g/kg, 유지 1.6~1.8g/kg, 컷 2.0~2.4g/kg, 컷 시 300~500kcal 결핍 권장

## 변경 범위
`lib/planGenerator.ts`의 프롬프트 문자열에 위 원칙을 고정 규칙 블록으로 추가한다. 인터페이스(`DayPlan`, `WeeklyPlan`, 함수 시그니처)는 변경 없음. 규칙 블록은 사용자의 `experienceLevel`, `environment`, `goal`, `weightKg`을 참조해 AI가 구체적 수치(예: 단백질 g수)를 계산해 넣도록 지시한다.

이렇게 생성된 `workout`/`diet` 텍스트는 오늘(`/today`) 탭의 체크리스트에 그대로 표시되므로, 별도 프론트엔드 변경 없이 오늘 탭 반영이 자동으로 이뤄진다.

## 테스트
`lib/planGenerator.test.ts`에 프롬프트 문자열이 규칙 키워드(예: "1RM", "g/kg", 휴식 분 등)를 포함하는지 확인하는 테스트 추가.

## 범위 밖
- 프론트엔드 UI 변경 없음
- DB 스키마 변경 없음
